# Как пользоваться OmegaZip на Mac (без глючного интерфейса)

## 1. Собрать приложение и CLI один раз

В терминале из папки проекта:

```bash
cd /Users/renat/01Project/OmegaZip
./build-app.sh
```

Скрипт соберёт и GUI (.app), и **консольную утилиту** и положит её внутрь приложения. После этого можно не открывать окно приложения вообще — всё делать из терминала или из контекстного меню.

---

## 2. Сжимать и распаковывать из терминала

Путь к консольной утилите после сборки (одна из двух, в зависимости от того, куда скопировали .app):

- Если .app лежит в проекте:  
  `./dist/OmegaZip.app/Contents/MacOS/omegazip`
- Если скопировали в Программы:  
  `/Applications/OmegaZip.app/Contents/MacOS/omegazip`

**Сжать файл или папку** (рядом появится `имя.oz`):

```bash
/Applications/OmegaZip.app/Contents/MacOS/omegazip compress /путь/к/файлу_или_папке
```

Или сохранить архив в нужное место:

```bash
/Applications/OmegaZip.app/Contents/MacOS/omegazip compress ~/Документы/МояПапка ~/Документы/МояПапка.oz
```

**Пресеты:** `--preset fast` (быстро), `balanced`, `max`, `ultra` (максимальное сжатие):

```bash
/Applications/OmegaZip.app/Contents/MacOS/omegazip compress --preset ultra ~/Документы/МояПапка ~/Документы/МояПапка.oz
```

**Распаковать** архив в папку:

```bash
/Applications/OmegaZip.app/Contents/MacOS/omegazip decompress архив.oz /путь/куда/распаковать
```

Пример: распаковать на рабочий стол рядом с архивом:

```bash
OZ="/Applications/OmegaZip.app/Contents/MacOS/omegazip"
$OZ decompress ~/Загрузки/архив.oz ~/Загрузки/архив_распакован
```

Чтобы не писать путь каждый раз, добавь алиас в `~/.zshrc`:

```bash
alias oz='/Applications/OmegaZip.app/Contents/MacOS/omegazip'
# или если .app в проекте:
# alias oz='/Users/renat/01Project/OmegaZip/dist/OmegaZip.app/Contents/MacOS/omegazip'
```

Дальше просто: `oz compress папка`, `oz decompress архив.oz куда`.

## 3. Контекстное меню в Finder: «Сжать OmegaZip» / «Распаковать OmegaZip»

Сервисы из Info.plist на Tauri **не работают** (система не передаёт файлы в приложение). Рабочий вариант — **Quick Action** в Finder, который вызывает консольную утилиту.

### Шаг 1: Убедись, что приложение собрано

Выполни один раз: `./build-app.sh` (из корня проекта). После этого в `dist/OmegaZip.app/Contents/MacOS/` лежит и `omegazip-app` (окно), и **omegazip** (CLI).

### Шаг 2: Создать Quick Action «Сжать OmegaZip»

1. Открой **Automator** (Программы → Утилиты → Automator).
2. **Файл → Новый** → выбери **Быстрое действие** (Quick Action).
3. Сверху задай:
   - **Получает текущее**: «файлы и папки» в **Finder**.
4. Слева выбери **«Запустить сценарий оболочки»**, перетащи в правую часть.
5. В выпадающем меню выбери **«Передать как аргументы»**.
6. Либо вставь один вызов (подставь свой путь к проекту):
```bash
/Users/renat/01Project/OmegaZip/scripts/quickaction-compress.sh "$@"
```
   Либо вставь этот сценарий целиком (подставь свой путь к .app, если он не в Программах):

```bash
OZ="/Applications/OmegaZip.app/Contents/MacOS/omegazip"
if [ ! -x "$OZ" ]; then
  OZ="$HOME/01Project/OmegaZip/dist/OmegaZip.app/Contents/MacOS/omegazip"
fi
for f in "$@"; do
  [ -e "$f" ] || continue
  out="${f}.oz"
  "$OZ" compress "$f" "$out" && echo "Сжато: $out"
done
```

7. **Файл → Сохранить** — имя, например: **Сжать OmegaZip**. Quick Action появится в **Сервисы** (и при правом клике в Finder).

### Шаг 3: Создать Quick Action «Распаковать OmegaZip»

Ещё одно быстрое действие:

1. Automator → **Файл → Новый** → **Быстрое действие**.
2. Получает: **файлы и папки** в **Finder**.
3. Добавь **«Запустить сценарий оболочки»**, **«Передать как аргументы»**.
4. Либо одна строка (свой путь к проекту):
```bash
/Users/renat/01Project/OmegaZip/scripts/quickaction-extract.sh "$@"
```
   Либо сценарий:

```bash
OZ="/Applications/OmegaZip.app/Contents/MacOS/omegazip"
if [ ! -x "$OZ" ]; then
  OZ="$HOME/01Project/OmegaZip/dist/OmegaZip.app/Contents/MacOS/omegazip"
fi
for f in "$@"; do
  [ -e "$f" ] || continue
  case "$f" in *.oz)
    dir="${f%.oz}_распаковано"
    "$OZ" decompress "$f" "$dir" && echo "Распаковано: $dir"
  ;; esac
done
```

5. Сохрани как **Распаковать OmegaZip**.

### Как пользоваться

- В Finder: правый клик по файлу/папке → **Сервисы** → **Сжать OmegaZip** (рядом появится `имя.oz`).
- Правый клик по `.oz` → **Сервисы** → **Распаковать OmegaZip** (появится папка `имя_распаковано`).

Если пунктов нет: **Finder → Настройки → Дополнения** — убедись, что нужные быстрые действия включены; можно перезапустить Finder.

---

## Итог

- **Приложение собрано** = после `./build-app.sh` есть `dist/OmegaZip.app` и внутри него CLI `Contents/MacOS/omegazip`.
- **Проверить сжатие** можно сразу из терминала командами выше или через алиас `oz`.
- **Контекстное меню** работает через Quick Action в Automator, а не через сломанные NSServices в .app.
