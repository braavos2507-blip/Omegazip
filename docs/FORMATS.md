# Матрица форматов OmegaZip

Источник поведения в коде: модуль `src/compat.rs` (список/распаковка «чужих» архивов), `src/pipeline.rs` (`compress_dispatch` — куда можно **сжать**). Уточнить на машине: **`omegazip deps`** (наличие 7-Zip).

## Таблица: чтение и запись

**Условные обозначения:** **Нативно** — без внешних процессов в ядре OmegaZip. **7-Zip** — нужен исполняемый файл `7z` / `7zz` / `7za` (или `7z.exe` в типичных путях Windows, см. `resolve_7z_executable` в `compat.rs`). **—** — не поддерживается.

| Группа | Примеры расширений | Чтение (распаковка / список) | Запись (создание архива) |
|--------|-------------------|-----------------------------|---------------------------|
| OmegaZip | `.oz` | Нативно | Нативно (`compress` → `.oz`) |
| ZIP-семейство | `.zip`, `.jar`, `.war`, `.apk`, `.ipa`, Office Open XML (`.docx`, `.xlsx`, …), `.cbz` | Нативно | Нативно (`compress` → `.zip`) |
| tar | `.tar`, `.tar.gz`, `.tgz`, `.tar.xz`, `.txz`, `.tar.bz2`, `.tbz2`, `.tbz`, `.tar.zst`, `.tzst` | Нативно | Нативно только **`.tar.gz` / `.tgz`** (`compress` → путь с таким суффиксом) |
| Одиночные потоки | `.gz`, `.xz`, `.bz2`, `.zst` (не tar) | Нативно | — (выход обычно `.oz` / `.zip` / `.7z` / `.tar.gz`) |
| CAB | `.cab` | Нативно | — |
| 7-Zip | `.7z` | 7-Zip | 7-Zip (`compress` → `.7z`, пароль опционально) |
| RAR | `.rar`, `.cbr` | 7-Zip | — (создание RAR не планируется) |
| Диски / установщики | `.iso`, `.wim`, `.swm`, `.esd`, `.dmg`, `.msi`, … | 7-Zip (по расширению или тесту `7z t`) | — |
| Пакеты Linux | `.deb`, `.rpm` | 7-Zip | — |
| Прочие из списка 7-Zip | `.arj`, `.lzh`, `.xar`, `.chm`, `.vhd`, … см. `extension_prefers_7z` в `compat.rs` | 7-Zip | — |

Если расширение не попало в таблицу, но файл открывает **7-Zip** (проверка `7z t`), OmegaZip может снова использовать 7-Zip для списка и распаковки.

## Ориентир «топ‑5» архиваторов

В требованиях v1.1 ориентиром названы возможности продуктов уровня **7-Zip, WinRAR, WinZip, Bandizip, PeaZip**. OmegaZip **не дублирует** все их кодеки внутри одного бинарника: для широкого набора контейнеров (RAR, ISO, MSI, многие «системные» форматы) на **десктопе** используется тот же практический подход, что и у экосистемы **7-Zip** — вызов установленного **7-Zip / p7zip**. Паритет с «архиватором из топа» для таких форматов означает: **если открывает ваш 7-Zip, OmegaZip сможет делегировать ему операцию** (при наличии бинарника).

Создание **RAR** вне scope проекта (проприетарный формат; см. `REQUIREMENTS.md`).

## Известные ограничения (FMT-02)

- **ZIP с шифрованием (нативный распаковщик):** не поддерживается — см. сообщение об ошибке в `compat.rs` (`PASSWORD_REQUIRED`). Пароль для **`.oz`** и для архивов **через 7-Zip** — отдельно в GUI/CLI.
- **Без 7-Zip на десктопе:** нет `.7z`, RAR, ISO, MSI и остальных форматов только из колонки «7-Zip».
- **OmegaZip Android:** внешний процесс 7-Zip **не используется**; доступны нативные форматы (`.oz`, ZIP, tar-семейство, одиночные gz/xz/bz2/zst, CAB и т.д. — см. статус в приложении и `seven_zip_install_howto` для Android в коде).
- **Запись:** нет создания CAB / отдельного `.zst`-контейнера как цели `compress` в том же смысле, что `.zip` (см. таблицу).

Пробелы без плана на v1.1 остаются **задокументированными**; расширение нативной матрицы — отдельные фазы.
