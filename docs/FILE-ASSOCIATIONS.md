# Ассоциации файлов и двойной щелчок

OmegaZip может открывать архивы при двойном щелчке в проводнике, если ОС передаёт путь приложению. Технически это событие `open-files` во фронтенде (см. `src-tauri/src/lib.rs`).

## Что настраивается установщиком

В `src-tauri/tauri.conf.json` заданы **fileAssociations** для ряда расширений (в т.ч. `.oz`, `.zip`, `.7z`, `.rar`). После установки bundle ОС предложит открывать эти типы в OmegaZip.

## Windows

1. Установите приложение из `.msi` / `.exe`, собранного Tauri.
2. **Параметр по умолчанию:** правый клик по файлу → «Открыть с помощью» → OmegaZip → при необходимости отметить «Всегда использовать это приложение».
3. Двойной щелчок запускает `OmegaZip.exe "C:\путь\архив.zip"` — путь попадает в приложение на старте.

## macOS

1. Установите `.app` из DMG или сборки.
2. **Назначить по умолчанию:** выделить файл → ⌘I → «Открыть с помощью» → OmegaZip → «Изменить всё…».
3. Событие открытия приходит через `RunEvent::Opened` (см. код).

Подробная интеграция с контекстным меню Finder, Quick Actions и шаблонами для Windows/Linux: [CONTEXT-MENU.md](CONTEXT-MENU.md) и `scripts/install-context-menu.sh`.

## Linux

1. Установите пакет / AppImage / deb в соответствии с вашим дистрибутивом.
2. Назначьте приложение по умолчанию для MIME-типов архивов: настройки системы → «Приложения по умолчанию» или `xdg-mime default ...`.
3. Путь к файлу передаётся аргументами командной строки при запуске (ветка `Ready` в Rust).

## Поведение в интерфейсе

При открытии **одного** архива (двойной щелчок или открытие из системы) поле **«Папка назначения»** для распаковки по умолчанию заполняется **каталогом, в котором лежит архив** (см. `ui/index.html`, логика `applyPaths`).

**Тихая распаковка без окна** при успехе: см. [SILENT-EXTRACT.md](SILENT-EXTRACT.md) (включение/исключения, переменная `OMEGAZIP_NO_SILENT_EXTRACT`).

## Ограничения

- Создание **RAR** не поддерживается; распаковка RAR возможна при наличии 7-Zip на десктопе.
- Несколько экземпляров при быстром открытии двух файлов зависят от ОС; при необходимости единственный экземпляр — отдельная доработка.
