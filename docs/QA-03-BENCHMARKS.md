# QA-03 — бенчмарки и регрессия

Полный **локальный чеклист** (baseline, профилирование, зоопарк, `.oz`): [MEASURABLE-QUALITY.md](MEASURABLE-QUALITY.md). Быстрые шаги плана: `npm run measure:oz-repo-corpora`, `npm run measure:profile-smoke`.

## CI (каждый PR)

Перекрёстная проверка **сжатие → распаковка** на синтетическом корпусе (текст, JSON, папка из нескольких файлов, бинарник → ZIP):

```bash
npm run test:bench-ci
# или
bash scripts/qa03-benchmark-ci.sh
```

Скрипт собирает `target/release/omegazip` при необходимости, сравнивает байты после roundtrip. **Время выполнения в CI не порогуется** (раннеры нестабильны).

## Локально: пресеты и объём

- **`scripts/bench.sh`** — несколько пресетов `.oz` на одном небольшом наборе, таблица скорости/коэффициента.
- **`scripts/benchmark-workflow.sh`** — сценарий «как в Finder»: `--preset auto` для `.oz`, большой синтетический корпус + опционально реальные файлы из каталога. На macOS по умолчанию ожидается бинарник из `OmegaZip.app` (см. скрипт). Пример отчёта: [BENCH_RESULTS.md](BENCH_RESULTS.md).

Реальные файлы для ручного прогона удобно класть в `tests/manual-files/downloads/` (не обязательно коммитить большие данные).

## Что ещё можно добавить (не сделано)

- Зафиксированные **пороги по времени** или размеру архива относительно эталона (хрупко на разном железе CI).
- Периодический job на **большом** корпусе вне каждого PR.
