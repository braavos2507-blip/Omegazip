# Установка OmegaZip и 7-Zip

Краткий **happy path** для десктопа. Полный список форматов: [FORMATS.md](FORMATS.md). Ассоциации файлов и ПКМ: [FILE-ASSOCIATIONS.md](FILE-ASSOCIATIONS.md), [CONTEXT-MENU.md](CONTEXT-MENU.md). Честное сравнение с ориентиром «топ-5»: [VERSUS-TOP5.md](VERSUS-TOP5.md).

## Сквозной сценарий: от установки до первой проверки

Один линейный путь для **конечного пользователя** (GAP-04): поставить OmegaZip, поставить **7-Zip / p7zip** для «внешних» форматов, убедиться, что всё видно в приложении, выполнить простую операцию.

### Что понадобится

| Компонент | Зачем |
|-----------|--------|
| **OmegaZip** (установщик или `.app` / AppImage / MSI из релиза) | GUI + CLI `omegazip`; нативные `.oz`, ZIP, tar, CAB и т.д. **без** отдельного Rust у пользователя. |
| **7-Zip** (Windows) или **p7zip** (macOS/Linux) | `.7z`, RAR, ISO, MSI, WIM и прочие форматы, которые не в нативной матрице — см. [FORMATS.md](FORMATS.md). |

**Размер:** готовый bundle Tauri обычно **десятки мегабайт** на платформу; точное значение смотрите на странице **релиза** (артефакты CI). Установка 7-Zip / пакета p7zip — отдельно, порядка нескольких мегабайт.

### Шаги

1. **Скачайте** OmegaZip с **страницы релизов** вашего репозитория (формат: DMG/MSI/AppImage/DEB и т.д. — что публикуете).
2. **Установите** OmegaZip стандартным для ОС способом (перетащить `.app` в «Программы», установщик MSI, `dpkg`/`rpm` — по вашей практике).
3. **Установите 7-Zip или p7zip** по инструкции ниже (раздел **7-Zip / p7zip** → **Как установить по ОС**).
4. **Запустите** OmegaZip. Вверху окна — баннер **7-Zip**: «найден» (зелёный) или предупреждение (жёлтый). Это и есть проверка без терминала.
5. **Дополнительно в терминале** (если ставили CLI в PATH или вызываете бинарник из bundle):
   ```bash
   omegazip deps
   ```
   Должен отображаться найденный исполняемый файл `7z` / `7zz` / `7za` или понятная подсказка по установке.
6. **Первая операция:**  
   - нативно: сожмите тестовый файл в **`.oz`** или **`.zip`** в GUI;  
   - с 7-Zip: откройте или создайте **`.7z`**, либо распакуйте **`.rar`** — после шага 3 это должно работать при успешном баннере.

### macOS: Gatekeeper и локальная сборка

Если система блокирует запуск неподписанного `.app`: см. [MACOS-RELEASE.md](MACOS-RELEASE.md) (quarantine: `xattr -cr`, Gatekeeper без codesign). Пути к локальной сборке: `dist/OmegaZip.app` после `./build-app.sh`.

### Приёмочный чеклист (ручной)

- [ ] OmegaZip запускается, интерфейс открывается.
- [ ] После установки 7-Zip/p7zip баннер в GUI показывает, что 7-Zip **найден**, либо `omegazip deps` подтверждает путь.
- [ ] Сжатие в `.oz` или `.zip` выполняется без ошибки.
- [ ] Операция с форматом **только через 7-Zip** (например открыть `.rar`) работает, если 7-Zip установлен; без него — ожидаемое сообщение об ошибке и ссылка на установку (см. баннер / `deps`).

**Подсказка при отсутствии 7-Zip:** в GUI при старте показывается предупреждение с ссылкой на [7-zip.org](https://www.7-zip.org/) и отсылкой к этому файлу и `FORMATS.md` — отдельный «первый раз при сжатии» не требуется, если пользователь уже видел баннер.

## OmegaZip

### Разработка из репозитория

1. [Rust](https://rustup.rs/) (stable), [Node.js](https://nodejs.org/) для фронта Tauri 2.  
2. Клонировать репозиторий, в корне:
   ```bash
   cargo build --release -p omegazip
   npm install
   npm run dev
   ```
   Сборка установочного пакета приложения:
   ```bash
   npm run build
   ```
   На macOS пункты **Сервисы** в Finder ставятся скриптом `./scripts/install-context-menu.sh` (см. [CONTEXT-MENU.md](CONTEXT-MENU.md)). Сборка `npm run build:macos` по умолчанию **не** добавляет `NSServices` в `.app` (чтобы не дублировать меню). При необходимости только инжекта в plist: `npm run build:macos:with-nsservices`.

### Конечный пользователь

Установите готовый артефакт из **релиза** вашего дистрибутива (формат зависит от CI: MSI/AppImage/DMG/DEB и т.д.). Конкретные ссылки не зашиваются в документ — смотрите страницу релизов проекта.

**Зависимости:** десктопное приложение — self-contained bundle Tauri (отдельно ставить Rust пользователю не нужно). Для расширенных форматов см. раздел про **7-Zip** ниже.

## 7-Zip / p7zip (FMT-03)

**Стратегия v1.1:** OmegaZip **не встраивает** бинарник 7-Zip в репозиторий. Используется **внешняя установка** и **автообнаружение**:

- Поиск `7z`, `7zz`, `7za` в `PATH`;
- на **Windows** — дополнительно типичные пути `Program Files\7-Zip\` и `Program Files (x86)\7-Zip\`;
- на **macOS** — дополнительно `/opt/homebrew/bin`, `/usr/local/bin` (Homebrew).

После установки перезапустите OmegaZip (или терминал для `omegazip`), чтобы обновился `PATH`.

### Как установить по ОС

- **Windows:** установщик с [7-zip.org](https://www.7-zip.org/). При установке в стандартную папку OmegaZip часто находит `7z.exe` даже без правки PATH.  
- **macOS:** `brew install p7zip` (обычно появляется `7zz`) или установка 7-Zip с сайта и добавление каталога с бинарником в PATH.  
- **Linux:** например `p7zip-full` / `p7zip-plugins` (Debian/Ubuntu, Fedora, Arch — см. подсказку в приложении или вывод `omegazip deps`).

### Проверка

```bash
omegazip deps
```

В GUI статус 7-Zip показывается в баннере при старте.

**OmegaZip Android:** внешний 7-Zip на устройстве не подключается; см. [FORMATS.md](FORMATS.md).
