# Тихая распаковка при открытии из системы (GAP-01)

Если OmegaZip назначен приложением по умолчанию для архива и вы открываете **один** файл двойным щелчком (или из macOS Services / аналога), приложение может **сразу распаковать** содержимое в **ту же папку**, где лежит архив, **без показа главного окна** при успехе.

## Когда срабатывает

- Передан **ровно один** существующий файл.
- Расширение входит в список «режим распаковки» (совпадает с GUI и с `omegazip::looks_like_supported_archive_path` в `src/compat.rs`).
- Включена опция в окне OmegaZip: **«Распаковывать сразу при открытии архива из системы»** (по умолчанию **включено**).

## Когда окно всё равно откроется

- Архив **с паролем** (или ошибка указывает на пароль / шифрование).
- Любая другая **ошибка** распаковки (нет 7-Zip для формата, повреждённый файл и т.д.).
- Передано **несколько** путей.
- Файл **не** считается поддерживаемым архивом по расширению (откроется сценарий сжатия/ручной распаковки).

В этих случаях окно показывается, путь подставляется в блок «Распаковать», в статусе — текст ошибки.

## Отключение

1. Снять флажок в разделе **Распаковать архив** в приложении.
2. Или задать переменную окружения **`OMEGAZIP_NO_SILENT_EXTRACT=1`** (или `true`) перед запуском — удобно для отладки.

Настройка флажка сохраняется в каталоге конфигурации приложения (файл `gui-prefs.json`).

## Ограничения (текущая версия)

- Нет индикатора прогресса при тихой распаковке (долгие архивы — подождите или отключите тихий режим).
- Повторный запуск второго архива может открыть второй процесс ОС (single-instance не реализован).
