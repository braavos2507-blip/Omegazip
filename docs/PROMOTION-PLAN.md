# План внешних публикаций OmegaZip

**Цель:** безбюджетное привлечение органического трафика, первых пользователей и донатеров через контент и внешние ссылки.
**Принцип:** честность и техническая глубина важнее «рекламности» — аудитория Habr/VC скептична к прямому пиару.

## Каналы (по приоритету)

| # | Канал | Формат | Зачем |
|---|-------|--------|-------|
| 1 | **Habr** | Техническая статья (флагман) | dev-аудитория, авторитетные ссылки, трафик |
| 2 | **Product Hunt** | Launch-пост | Международная видимость, обратная ссылка |
| 3 | **AlternativeTo** | Страница OmegaZip как альтернатива 7-Zip/WinRAR | Вечнозелёный трафик + dofollow-ссылка |
| 4 | **VC.ru** | Короткий пост (предпринимательский угол) | Широкая RU-аудитория |
| 5 | **GitHub** | README-ссылка на omegazip.ru | Уже есть, проверить что ведёт на `.ru`, не `.cloud` |
| 6 | **Reddit** (r/rust, r/selfhosted, r/DataHoarder) | AMA-стиль пост | Тематические энтузиасты |
| 7 | **Соцсети/чаты** | Анонс + гифка меню Windows | Дополнительный охват |

## Контент-календарь (6 недель)

- **Неделя 1** — Habr-статья (файл `docs/habr-omegazip.md`) + запуск на Product Hunt.
- **Неделя 2** — VC.ru: переработка статьи под «почему я бросил вызов 7-Zip».
- **Неделя 3** — AlternativeTo (создать страницу) + закрепить ссылку в GitHub README.
- **Неделя 4** — Reddit + короткое видео/гифка контекстного меню Windows.
- **Неделя 5–6** — ответы на комментарии, вторая статья-глубокое погружение: «Как устроен формат .oz изнутри» (байтовый разбор).

## Чек-лист ДО публикации

- [ ] Сайт задеплоен (`npm run site:deploy`), `sitemap.xml` отправлен в GSC и Вебмастер.
- [ ] Яндекс.Метрика активирована (ID в `site/config.json`).
- [ ] Ссылки в README ведут на `omegazip.ru`, не на мёртвый `omegazip.cloud`.
- [ ] Бенчмарки свежие (`npm run measure:everything-local`), цифры в статье актуальны.
- [ ] Автор готов оперативно отвечать в комментариях (на Habr это обязательно).

## KPI (что мерить)

- Индексация новых страниц (GSC/Вебмастер).
- Посещаемость и источники (Метрика).
- Количество внешних ссылок (Habr, VC, AlternativeTo, PH).
- Донаты и звёзды на GitHub.

## Риски

- **Скепсис к «рекламе»** на Habr → ставка на техглубину, код и честные цифры (включая проигрыши).
- **SmartScreen / неподписанный установщик** → в статье акцентировать проверку SHA-256 и скачивание только с официального домена.
- **Токсичность сравнений** («ты лучше 7-Zip?») → явно писать границы: .oz не LZMA2, 7-Zip сильнее на одиночном файле.
