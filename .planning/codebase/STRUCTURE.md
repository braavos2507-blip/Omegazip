## Directory Purposes

**`src/`** — Core compression library (no UI, pure Rust)
- Purpose: Implements the 4-stage compression pipeline, codecs, encryption, recovery, deduplication
- Contains: Reusable library code suitable for both CLI and GUI
- Key files: `pipeline.rs` (main orchestration), `analyzer.rs`, `codec.rs`, `crypto.rs`, `recovery.rs`

**`src-tauri/src/`** — Tauri backend IPC handlers
- Purpose: Connect desktop UI to compression library
- Contains: Command handlers that accept frontend requests, emit progress events, manage platform-specific dialogs
- Key files: `lib.rs` (all command implementations), `macos_services.rs` (native integration)

**`ui/`** — Frontend HTML/CSS/JavaScript
- Purpose: User interface for compression tasks
- Contains: Single HTML file with embedded styles and inline JavaScript
- Key files: `index.html` (540x580 responsive layout with drag-drop, file pickers, progress bars)

**`scripts/`** — Build, integration, and external tools
- Purpose: Automate compilation, sign macOS bundles, provide analyzer/preprocessor stubs
- Key files: `build-app.sh` (production build), `inject-macos-services.sh` (macOS signing), `detect_context.sh` (optional analyzer)

**`dist/`** — Build output
- Purpose: Final application bundle ready for distribution
- Contains: `OmegaZip.app` (macOS), CLI binary embedded in app
- Generated by: `build-app.sh`

## Key File Locations

**Entry Points:**
- `src-tauri/src/main.rs`: Desktop app main() - delegates to lib.rs run()
- `src/main.rs`: CLI binary main() - parses args, dispatches to library functions
- `ui/index.html`: Frontend entry - loaded by Tauri window

**Configuration:**
- `Cargo.toml`: Rust workspace, library dependencies (zstd, lz4, xz2, chacha20poly1305, argon2, reed-solomon-erasure)
- `src-tauri/Cargo.toml`: Tauri app specifics (tauri, tauri-plugin-dialog, tauri-plugin-fs)
- `src-tauri/tauri.conf.json`: Tauri config (window 540x580, frontendDist: ../ui, bundle settings)
- `package.json`: npm scripts (npm run tauri dev, npm run tauri build)

**Core Logic:**
- `src/pipeline.rs`: compress_to_path_with_options(), decompress_to_path_with_options() - orchestrates 4-stage pipeline
- `src/analyzer.rs`: analyze_bytes(), analyze_file() - semantic analysis for codec selection
- `src/codec.rs`: best_compress(), Codec dispatch
- `src/dedup.rs`: BlockStore - global deduplication
- `src/crypto.rs`: encrypt_block(), decrypt_block(), derive_key() - password-based encryption
- `src/recovery.rs`: encode_stripe(), decode_stripe() - Reed-Solomon recovery

**Testing:**
- No test directory; tests are inline in modules (Rust convention)
- Example: `src/huffman.rs` likely contains #[cfg(test)] module

**Tauri Commands:**
- `src-tauri/src/lib.rs` line 14-91: Command definitions (compress, decompress, archive_info, export_to_zip, file pickers, rclone)
- `src-tauri/src/lib.rs` line 342-358: invoke_handler! macro registers all commands

## Naming Conventions

**Files:**
- Rust modules: `snake_case.rs` (e.g., `pipeline.rs`, `codec_backend.rs`)
- CLI binary: `main.rs`
- Tauri lib: `lib.rs`
- Configuration: `Cargo.toml`, `tauri.conf.json`, `package.json`
- Scripts: `lowercase-with-dashes.sh`

**Directories:**
- Rust source: `src/`, `src-tauri/src/`
- Frontend: `ui/`
- Build output: `dist/`, `target/`, `out/`
- Scripts: `scripts/`
- Documentation: `docs/`

**Functions:**
- Library public functions: `snake_case` (e.g., `compress_to_path`, `archive_info`, `decompress_to_path_with_options`)
- Tauri commands: `snake_case` with #[tauri::command] attribute
- Internal helpers: `snake_case` (e.g., `hex_to_hash`, `crc32_bytes`)

**Types/Structs:**
- PascalCase (e.g., `Codec`, `DataContext`, `CompressOptions`, `ArchiveInfo`, `Progress`, `BlockStore`)
- Enums: PascalCase variants (e.g., `ProgressPhase::Scanning`)

**Variables:**
- snake_case (e.g., `archive_path`, `compression_options`, `progress`)
- Constants: UPPER_SNAKE_CASE (e.g., `STRIPE_DATA_SHARDS`, `BLOOM_BITS`, `DEFAULT_CHUNK_SIZE`)

## Where to Add New Code

**New Compression Feature (e.g., new codec):**
- Implementation: `src/codec_backend.rs` (add codec functions) + update `src/codec.rs` (add Codec variant and dispatch)
- Tests: Inline in respective module with #[cfg(test)]
- Integration: Update pipeline.rs if it affects overall flow

**New Tauri Command (e.g., archive listing with filters):**
- Handler: `src-tauri/src/lib.rs` (add #[tauri::command] function, invoke_handler! registration)
- Backend: Create public function in `src/lib.rs` if it's a new library capability, or reuse existing (e.g., list_archive)
- Frontend: `ui/index.html` - add button, invoke command via window.__TAURI__.core.invoke()

**New CLI Subcommand (e.g., analyze archive):**
- CLI handler: `src/main.rs` (add match arm in main() for new subcommand, parse args)
- Backend: Call library function from `src/lib.rs` public API
- No frontend changes needed

**New Utility/Helper Module:**
- Location: `src/utils.rs` (if generally useful) or `src/<feature>_utils.rs` (if feature-specific)
- Export: Add to `src/lib.rs` pub mod declaration if it should be public library API
- Naming: `snake_case.rs`, functions `snake_case`

**Analyzer/Preprocessor External Script:**
- Shell script: Add to `scripts/` directory
- Integration: Reference in pipeline.rs via env::var() lookup (e.g., OMEGAZIP_ANALYZER_SCRIPT, OMEGAZIP_PREPROCESS_PDF)
- Frontend: Optionally add UI toggle to enable/disable in compress_advanced options

## Special Directories

**`src-tauri/gen/`** — Generated by Tauri build
- Purpose: Auto-generated Tauri bindings and schemas
- Generated: By tauri-build during compilation
- Committed: No (git-ignored)

**`src-tauri/icons/`** — App icons
- Purpose: macOS, Windows, Linux app icons in multiple sizes
- Committed: Yes
- Update: Replace PNG/ICO files; tauri bundle picks them up automatically

**`dist/`** — Build output for distribution
- Purpose: Final application bundle (OmegaZip.app)
- Generated: By `build-app.sh` script
- Committed: No (git-ignored)

**`target/`** — Cargo build directory
- Purpose: Compiled artifacts, dependencies
- Generated: By cargo build/release
- Committed: No

## Frontend Structure (ui/index.html)

Single HTML file with embedded CSS and JavaScript:

**CSS Sections:**
- CSS variables (--primary, --border, --radius, etc.) for theming
- Component styles (.card, .btn-primary, .drop-zone, .path-row, .progress-bar)
- Layout: 2-column (compress on left, extract on right)

**JavaScript Structure:**
- Tauri initialization: window.__TAURI__ API access
- UI state management: selected paths, options (chunked, solid, recovery, password)
- Event listeners:
  - File picker buttons: window.__TAURI__.core.invoke('pick_folder', {}) → update UI path display
  - Compress button: invoke('compress_advanced', { source, archive_path, ...options })
  - Decompress button: invoke('decompress_with_password', { archive_path, dest_dir, password })
  - Drag-drop: listen to 'drop-files' event, populate file paths
- Progress tracking: listen to 'compress-progress', 'decompress-progress' events → update progress bar UI
