## v1.2 Requirements — строгое ТЗ: только пробелы (**новая работа**)

Не дублировать PATH / SMART / базовую матрицу FMT / существующие ассоциации — только то, чего **ещё нет**.

- [x] **GAP-01** (**п.1 ТЗ, часть B**): Один архив из ОС → распаковка в каталог архива **без главного окна** при успехе; пароль/ошибка → окно + `silent-extract-failed`. Док: `docs/SILENT-EXTRACT.md`.
- [ ] **GAP-02** (**п.6 ТЗ, часть B**): Интеграция ПКМ **Windows** и **Linux** ближе к «из коробки»: установляемый артефакт или скрипт с понятным шагом (не только правка `.reg` вручную); обновить `CONTEXT-MENU.md` и приёмочные критерии.
- [ ] **GAP-03** (**п.3 ТЗ**): Явный документ **«OmegaZip vs топ-5»**: по каждому формату/классу — Native / через 7-Zip / не поддерживается; зафиксировать **намеренный** non-parity где он нецелесообразен; при необходимости **один** приоритетный нативный пробел (только если малый diff — решение в `plan-phase`).
- [ ] **GAP-04** (**п.5 ТЗ**): Усилить **лёгкость установки**: единый сценарий в README/INSTALL (размер, зависимости, 7-Zip), опционально подсказка при первом сжатии «внешнего» формата без 7-Zip.
- [ ] **GAP-05** (**п.6, трей**, опционально): Иконка в трее / сворачивание в фон после базового GAP-01/02.
