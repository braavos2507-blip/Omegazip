## v1.1 Requirements — ТЗ интеграция и умолчания (2026-03-30)

### Интеграция с ОС

- [x] **SHELL-01**: Распаковка по **двойному щелчку** по поддерживаемым расширениям через регистрацию ассоциаций (Windows: ProgID/OpenWith; macOS: CFBundleDocumentTypes / роль приложения; Linux: `.desktop` + MIME).
- [x] **SHELL-02**: Контекстное меню (ПКМ) для файла/папки: пункты **«Сжать в .oz»** / **«Сжать в .zip»** (и при необходимости распаковка), вызов без обязательного показа главного окна (фон/минимальный UI).
- [x] **SHELL-03**: Опциональный **режим в трее** / фоновая работа согласована с ТЗ (не блокирует сценарий «только ПКМ»).

### Пути и имена по умолчанию

- [x] **PATH-01**: По умолчанию **каталог назначения** при распаковке = каталог, где лежит **архив** (с возможностью смены в настройках).
- [x] **PATH-02**: По умолчанию **каталог для нового архива** = каталог **исходного файла или папки** (согласовано с диалогом сохранения или без лишнего шага).
- [x] **PATH-03**: Имя архива **совпадает с базовым именем источника** + выбранное расширение (уже в UI; проверить macOS Services / CLI / контекстное меню).

### Форматы (ориентир «топ-5»)

- [x] **FMT-01**: Документ **матрицы форматов**: нативно vs 7-Zip vs «не поддерживается»; сравнение с возможностями ведущих архиваторов (как минимум: 7-Zip, WinRAR, WinZip, Bandizip, PeaZip — уточняем список при планировании).
- [x] **FMT-02**: План закрытия **явных пробелов** (новые нативные форматы или документированные ограничения).
- [x] **FMT-03**: Стратегия **поставки 7-Zip** (bundled optional, установщик, или авто-обнаружение) — зафиксировать в INSTALL.md.

### Установка

- [x] **INST-01**: Сценарий **«лёгкая установка»**: один понятный путь (MSI/Inno/portable .app/dmg/AppImage или комбинация) + размер и зависимости в README.
- [x] **INST-02**: Проверка **первого запуска**: статус 7-Zip, ссылка на установку без простыни текста в лицо пользователю.

### Умные пресеты (п.7 ТЗ)

- [x] **SMART-01**: Таблица соответствия **категория файла / расширение → профиль сжатия** (oz: fast/balanced/max; для несжимаемого — store/без лишнего CPU).
- [x] **SMART-02**: Гарантия **отсутствия потерь** для lossless-типов (код, диски, текст); для уже сжатых медиа — **не перекодировать**, по возможности store или слабое сжатие без изменения потока.
