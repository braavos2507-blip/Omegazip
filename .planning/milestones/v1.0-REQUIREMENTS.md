## v1.0 Requirements (снимок на дату закрытия)

### Core (ядро Rust)

- [x] **CORE-01**: CLI `compress` / `decompress` / `export-zip` / `info` / `list` / `deps` для заявленных форматов и сообщений об ошибках
- [x] **CORE-02**: Безопасная распаковка (`safe_join`, защита от path traversal)
- [x] **CORE-03**: Интеграционные тесты совместимости (ZIP, tar.gz, zst и др. по CI)

### GUI (Tauri)

- [x] **GUI-01**: Выбор файлов/папок, сжатие и распаковка с отображением прогресса
- [x] **GUI-02**: Статус 7-Zip и понятные подсказки, если бинарник не найден
- [x] **GUI-03**: Имя выходного архива по умолчанию от базового имени источника (реализовано в UI/CLI; проверить все пути)

### Android

- [x] **AND-01**: Сборка с продуктовым именем **OmegaZip Android** и отдельным UI при необходимости
- [x] **AND-02**: Заглушки/сообщения для функций, недоступных без 7-Zip и rclone
- [x] **AND-03**: Документация сборки (`ANDROID_BUILD.md`) и предпосылки SDK

### Quality

- [x] **QA-01**: CI зелёный на `ubuntu-latest` и `macos-latest` (`cargo test` + `src-tauri` `cargo check`)
- [x] **QA-02**: Документация (README, `docs/`, Правки) согласована с кодом
