# Phase 9 — RESEARCH: тихая распаковка при открытии архива (GAP-01)

**Дата:** 2026-03-29  
**Требование:** **GAP-01** (дополняет SHELL-01b)

## Цель

При открытии **ровно одного** файла-архива из ОС (ассоциация / двойной щелчок) выполнить распаковку в **каталог архива** без обязательного показа **главного окна** Tauri. Ошибки и запрос пароля — предсказуемое поведение (см. ниже).

## Текущее поведение

- `lib.rs`: `RunEvent::Opened` (macOS) / `RunEvent::Ready` + `args()` (Windows/Linux) → `emit("open-files", paths)`.
- `ui/index.html`: `listen('open-files')` → `applyPaths` → заполняются поля распаковки; **окно уже видимо**; пользователь жмёт кнопку распаковки.

## Варианты реализации

| Подход | Плюсы | Минусы |
|--------|--------|--------|
| **A. Rust `setup` + скрыть окно** | Нет дублирования логики декомпрессии в JS; один процесс | Нужна синхронизация с macOS `Opened` (может прийти после старта) |
| **B. Только фронт: скрытое окно + auto-invoke decompress** | Меньше Rust | Окно/WebView всё равно грузится; хуже для «без архиватора» |
| **C. Отдельный бинарник-лаунчер** | Идеальное разделение | Дублирование сборки, ассоциации на другой exe |

**Рекомендация плана:** **A** — в `src-tauri` после создания окна **сразу** `hide()` если сценарий «silent candidate», затем на **главном/логическом потоке** (с учётом Tauri) вызвать `omegazip::decompress_any_to_path_with_options` (или обёртку без прогресса в silent-режиме). Успех → `app.exit(0)`. Ошибка / нужен пароль → `show()` + `emit("open-files", …)` + опционально `emit("silent-extract-failed", reason)`.

## Платформы

- **Windows/Linux:** пути из `std::env::args()` доступны к моменту `setup` (как сейчас в `Ready` — продублировать критерий «один существующий путь = архив»).
- **macOS:** URL приходят в `Opened`; если окно уже показано — в обработчике `Opened` повторить ту же ветку «silent» (общая функция `try_silent_extract(app, paths)`).

## Критерии «один архив»

Переиспользовать ту же эвристику расширений, что **`isExtractArchivePath`** в `ui/index.html`, или вынести в общий список в Rust (предпочтительно — **один источник правды** в `omegazip` или `src-tauri`, чтобы GUI и silent совпадали).

## Краевые случаи

| Случай | Поведение (предлагаемое) |
|--------|---------------------------|
| Нужен пароль | Показать окно, `open-files`, фокус на распаковке, статус «требуется пароль» |
| Несколько путей в args | Текущее поведение — полное окно |
| Путь не архив | Полное окно (или только compress — как сейчас `applyPaths`) |
| Ошибка 7-Zip / формат | Показать окно **или** нативный диалог ошибки (минимум — окно + сообщение) |
| Пользователь отключил silent | Настройка в UI + persist (`tauri-plugin-store` или файл в `app_config_dir`) |

## Риски

- **Производительность:** большой архив без UI прогресса — допустимо для v1; опционально нативный прогресс/OS notification в follow-up.
- **single-instance:** второй запуск при открытии другого файла — вне минимального GAP-01; упомянуть в SUMMARY как follow-up.
