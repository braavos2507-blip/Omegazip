## Сравнение с «топ‑5» (для FMT-01)

Ориентиры из REQUIREMENTS: 7-Zip, WinRAR, WinZip, Bandizip, PeaZip — не как обязательный бенчмарк кода, а как **контекст для таблицы**: OmegaZip на десктопе для форматов **вне нативного ядра** опирается на **тот же класс возможностей**, что и установленный **7-Zip** (распаковка RAR/ISO/…; создание `.7z`). Создание **RAR** — вне scope (`REQUIREMENTS` Out of Scope).

## Пробелы (черновик для FMT-02)

- Зашифрованный ZIP — ограничение в `compat.rs` (сообщение про пароль).
- RAR — только чтение через 7-Zip.
- Android — без внешнего 7-Zip; список уже в `seven_zip_install_howto()` для android.

Детализация — в `docs/FORMATS.md` (план).

## Установка (INST-01 / INST-02)

- **Сборка:** `README` уже даёт `cargo build`, `npm run tauri build` кратко; нет единого «happy path» по шагам для конечного пользователя (MSI/DMG/AppImage — зависит от CI/релиза).
- **7-Zip (FMT-03):** стратегия фактически **«внешняя зависимость + автообнаружение»**, не bundle в репозитории — это нужно **явно зафиксировать** в `INSTALL.md` (опционально: будущий bundled — как follow-up, не блокер v1.1).
