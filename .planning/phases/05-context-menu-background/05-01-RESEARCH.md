# Phase 5 — RESEARCH: ПКМ, фон, пути по умолчанию

**Требования:** SHELL-02, SHELL-03, PATH-02, PATH-03

## Текущее состояние

| Механизм | Что есть |
|----------|----------|
| **macOS** | `scripts/install-context-menu.sh` — Quick Actions «Сжать в OmegaZip» (→ `.oz` рядом с файлом), «Распаковать» (только `.oz` → папка `*_распаковано`). Вызов через **CLI** `omegazip` внутри `.app` — **окно Tauri не нужно**. |
| **Windows** | Нет готового shell extension; пользователь может вручную создать ярлыки/ассоциации. Документация из фазы 4 не покрывает ПКМ-сжатие. |
| **Linux** | Нет шаблона `.desktop` с действиями «Сжать в .oz / .zip». |
| **GUI Tauri** | При «Куда сохранить» имя по умолчанию от базового имени источника (фаза 4+). Нет стартового каталога диалога = папка источника (PATH-02 для GUI). |

## Цели фазы

- **SHELL-02:** Два явных действия контекстного меню (или эквивалент): **сжать в .oz** и **сжать в .zip** (ТЗ v1.1).
- **SHELL-03:** Базовый сценарий без главного окна — **CLI из ПКМ** удовлетворяет; «трей» — опционально, низкий приоритет.
- **PATH-02:** Архив создаётся **в той же папке**, что и источник (скрипты уже кладут рядом; проверить именование).
- **PATH-03:** Имя архива = **базовое имя источника** + расширение (не `file.txt.oz` при желании «stem» — уточнить: для файла `a.txt` → `a.oz` или `a.txt.oz`; в ТЗ — «как название файла но с расширением» → обычно **stem + .oz**).

## Риски

- **Windows:** полноценный Cascading Context Menu — MSI/custom action; MVP — `.reg` + `cmd /c` на `omegazip` в PATH.
- **Finder Services vs Quick Actions:** текущий скрипт использует `~/Library/Services` + workflow — оставляем этот путь, расширяем пунктами.
