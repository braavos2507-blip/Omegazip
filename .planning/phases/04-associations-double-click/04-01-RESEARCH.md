# Phase 4 — RESEARCH: ассоциации и открытие файлов

**Дата:** 2026-03-30  
**Требования:** SHELL-01, PATH-01

## Текущее поведение OmegaZip (код)

| Платформа | Как приложение получает путь к файлу |
|-----------|----------------------------------------|
| **macOS** | `RunEvent::Opened { urls }` → emit `open-files` |
| **Windows / Linux** | `RunEvent::Ready` → `std::env::args().skip(1)`, существующие пути → `open-files` |

**Windows:** аргументы после имени exe обычно содержат полный путь к файлу при открытии из проводника; отфильтровываются только существующие пути (`Path::exists`). Проверить на чистой установке MSI, что путь с пробелами и UNC не ломается.
| **macOS Services** | Pasteboard на `Resumed` (обходной путь; не полноценный openFiles из Finder) |

**UI:** `listen('open-files')` → `applyPaths` → если путь похож на архив, выставляется `extractSrc`, иначе `compressSrc`. **Папка распаковки по умолчанию не выставляется** — пользователь жмёт «Папка назначения».

## Цель фазы

1. **SHELL-01:** Пользователь может назначить OmegaZip обработчиком по двойному щелчку (документация + при необходимости скрипты/расширение `fileAssociations` в Tauri).
2. **PATH-01:** При открытии архива через `open-files` **по умолчанию** предлагать распаковку в **каталог, где лежит архив** (клиент: `dirname(archive)`), без обязательного лишнего клика.

## Платформы

### Windows

- Установщик / `fileAssociations` в `tauri.conf.json` регистрирует ProgId (Tauri bundle).
- Двойной щелчок обычно запускает `OmegaZip.exe "C:\path\file.zip"` — текущая логика `args()` совместима.
- Проверить: не съедаются ли флаги при обёртках (MS Store, ярлыки).

### macOS

- `bundle.fileAssociations` + `Info.plist` / генерация Tauri.
- Событие `Opened` уже есть — двойной щелчок по файлу с заявленным UTI должен попадать в приложение.
- Расширить список ассоциаций (не только `.oz`).

### Linux

- `.desktop` с `MimeType=` и `%F`; пакет/ AppImage должны регистрировать MIME через `xdg-mime` (документация).
- `args()` на `Ready` — проверить в основных DE (GNOME/KDE).

## Риски

- **Один инстанс:** двойной щелчок по второму файлу может открыть второй процесс — при необходимости позже `single_instance` + передача пути в уже запущенное окно (вне scope минимального PATH-01, зафиксировать в плане как follow-up).
- **Безопасность:** распаковка «в ту же папку» должна оставаться с `safe_join` (уже в ядре).
