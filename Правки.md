## 2026-03-29 — Сводка доработок (для анализа)

Ниже перечислены изменения, внесённые в ходе доработки совместимости форматов, 7-Zip, UX и тестов. Устаревшие утверждения старых разделов этого файла (про «нет RAR/7z») **заменены этой сводкой** там, где есть противоречие.

### 1. Ядро: `src/compat.rs`

- **ZIP:** при зашифрованном ZIP без пароля — понятное сообщение на русском (`ZipError::PASSWORD_REQUIRED`), а не сырая ошибка `zip`.
- **Форматы нативно (Rust):** ZIP и ZIP-контейнеры (jar, apk, docx, odp, cbz и т.д.), tar / tar.gz / tar.xz / tar.bz2, **tar.zst / .tzst**, одиночные **.gz / .xz / .bz2 / .zst**, **CAB** (крейт `cab`).
- **7-Zip / p7zip (внешний процесс):** если в системе есть `7zz`, `7z` или `7za` (на Windows дополнительно поиск `Program Files\7-Zip\*.exe`; на macOS — типичные `brew` префиксы `/opt/homebrew/bin`, `/usr/local/bin`, `/opt/local/bin`), то **распаковка и список** для `.7z`, `.rar`, `.iso`, `.wim`, `.msi`, `.dmg`, `.deb`, `.rpm`, `.xar`, `.lzma`, `.arj`, `.lzh` и др., а также **проба** `7z t` для неочевидных файлов.
- **Создание:** `compress_to_tar_gz`, `compress_to_7z` (через `7z a`); пароль для `.7z` — из расширенных опций сжатия.
- **Безопасность путей:** `safe_join` при распаковке (traversal / абсолютные пути внутри архива).
- **Статус 7-Zip для UI/CLI:** структура `SevenZipStatus` (serde), `seven_zip_status()`, `seven_zip_install_howto()`, константы `SEVENZIP_PATH_HINT`, `RAR_FORMAT_NOTE`.
- **Ошибки:** при отсутствии 7-Zip — `sevenz_missing_error()` (подсказка + инструкции по ОС); при «неизвестном формате» — доп. текст в зависимости от того, найден ли 7-Zip.

### 2. Пайплайн: `src/pipeline.rs`

- **Манифест при сжатии:** `relative_path_for_manifest` — `canonicalize` для базы и каждого файла, чтобы на macOS не ломался `strip_prefix` из‑за `/var/...` vs `/private/var/...`.
- **`decompress_any_to_path_with_options`:** пароль передаётся в `compat::extract_foreign_with_password` (для 7-Zip/RAR и т.д.; нативный зашифрованный ZIP по-прежнему с ограничениями крейта `zip`).
- **`list_any_archive_with_password`** + обёртка `list_any_archive`.
- **`compress_dispatch` / `compress_advanced_dispatch`:** ветки для **`.tar.gz`/`.tgz`** и **`.7z`**; для tar.gz пароль запрещён с явной ошибкой; для ZIP — пароль по-прежнему запрещён.

### 3. CLI: `src/main.rs`

- Команда **`deps`** — вывод статуса 7-Zip, пути к бинарнику, заметки про RAR, инструкций по установке.
- Команда **`list`** — опции **`--password` / `--password-file`** (и env как у decompress).
- Обновлена справка (usage) под новые форматы и `deps`.

### 9. Актуальные ограничения (после доработок)

| Тема | Статус |
|------|--------|
| Создание **RAR** | Не поддерживается (проприетарный формат WinRAR). |
| Нативный **ZIP с паролем** | Распаковка только незашифрованных; шифрованный — сообщение + опционально пользователь ставит 7-Zip и открывает через него вручную не через наш нативный путь. |
| **7-Zip** | Обязателен в PATH (или стандартная установка на Windows / типичные пути на macOS) для форматов, которые не закрыты нативным Rust. |
| **Quantum CAB** и редкие методы в CAB | Крейт `cab` может вернуть ошибку — тогда только 7-Zip, если умеет. |
| **Нотаризация / подпись Apple** | Не автоматизированы в репозитории. |

## Android — будет ли работать приложение?

**Текущий продукт (Tauri GUI + этот репозиторий) — нет, как готовое Android-приложение.**

Причины:

1. **Конфигурация:** `tauri.conf.json` ориентирован на **десктоп** (`identifier` с суффиксом desktop, окна под macOS/Windows/Linux). Сборки **APK/AAB** в проекте не настроены.
2. **Rust-ядро:** теоретически библиотеку `omegazip` можно собирать под **Android (target `aarch64-linux-android` и др.)** через NDK, но понадобятся правки под мобильную среду (пути, память, отсутствие некоторых API).
3. **7-Zip:** распаковка «как у десктопа» завязана на **`std::process::Command`** и бинарник **7z в системе**. На Android **нет** такого же PATH и установленного p7zip; встроить нативный `7z` в APK — отдельная задача (лицензия LGPL, размер, JNI/обёртка).
4. **Tauri Mobile:** у Tauri есть направление **iOS/Android**, но это отдельный цикл: мобильный runtime, разрешения, хранилище, UI. Текущий **WebView + invoke** код не проверен под Android.
5. **rclone, диалоги файлов, сервисы macOS** — на Android не применимы в том же виде.

**Итог:** для Android нужен **отдельный таргет** (например только библиотека + Kotlin/Jetpack Compose или Flutter с FFI, либо официальный мобильный pipeline Tauri с большой доработкой). **«Из коробки» Android не поддерживается.**

### Какие форматы может **создавать** (актуализировано)

| Выходной файл | Описание |
|---------------|----------|
| **`.oz`** | Нативный OmegaZip: семантический анализ, выбор кодеков, опционально чанки, solid, шифрование, recovery. |
| **`.zip`** | ZIP Deflate; пресеты/чанки/solid/recovery не применяются; пароль ZIP не поддерживается. |
| **`.tar.gz` / `.tgz`** | Нативно через `tar` + `flate2`. |
| **`.7z`** | Через установленный 7-Zip (`7z a`); пароль — из расширенного сжатия. |

---

### Какие форматы может **распаковывать** (актуализировано)

- **Нативно:** `.oz`, ZIP-семейство, tar\* , gz/xz/bz2/zst по правилам `compat`, **CAB** (ограничения крейта).
- **Через 7-Zip (если установлен):** 7z, RAR, ISO, WIM, MSI и пр. — см. сводку и `README.md`.

**RAR:** только распаковка; создание `.rar` не поддерживается.

### Методика замеров для главного разработчика (скопировать и выполнить локально)

```bash
cd /path/to/OmegaZip
cargo build --release
BIN=./target/release/omegazip

# Проверка зависимостей 7-Zip
"$BIN" deps

# Повторяющийся текст (~5 МБ)
python3 -c "open('/tmp/repeat.txt','w').write(('bench line\\n'*200000))"
# Псевдослучайные данные (~2 МБ)
python3 -c "import os; open('/tmp/random.bin','wb').write(os.urandom(2*1024*1024))"

/usr/bin/time -p "$BIN" compress /tmp/repeat.txt /tmp/repeat.oz
/usr/bin/time -p "$BIN" compress /tmp/repeat.txt /tmp/repeat.zip
ls -l /tmp/repeat.txt /tmp/repeat.oz /tmp/repeat.zip

/usr/bin/time -p "$BIN" compress /tmp/random.bin /tmp/random.oz
ls -l /tmp/random.bin /tmp/random.oz

mkdir -p /tmp/out_oz /tmp/out_zip
/usr/bin/time -p "$BIN" decompress /tmp/repeat.oz /tmp/out_oz
/usr/bin/time -p "$BIN" decompress /tmp/repeat.zip /tmp/out_zip
cmp /tmp/repeat.txt /tmp/out_oz/repeat.txt && echo "OZ OK" || echo "OZ FAIL"
cmp /tmp/repeat.txt /tmp/out_zip/repeat.txt && echo "ZIP OK" || echo "ZIP FAIL"

# tar.gz (системный tar)
tar -czf /tmp/repeat.tar.gz -C /tmp repeat.txt
mkdir -p /tmp/out_tgz
/usr/bin/time -p "$BIN" decompress /tmp/repeat.tar.gz /tmp/out_tgz
cmp /tmp/repeat.txt /tmp/out_tgz/repeat.txt && echo "TGZ OK" || echo "TGZ FAIL"
```

Зафиксировать: время **real**, размеры файлов, **% размера архива от исходного** = `100 * archive_bytes / source_bytes`.
