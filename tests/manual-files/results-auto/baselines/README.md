# Логи baseline (`baseline-all-local.sh`)

Сюда пишутся файлы `baseline-YYYYMMDD-HHMMSS.log` при запуске:

```bash
bash scripts/baseline-all-local.sh
```

Имеет смысл **не коммитить** каждый лог; сохраняйте вручную только опорные прогоны (перед/после крупных изменений) или копируйте цифры в [docs/BENCH_RESULTS.md](../../BENCH_RESULTS.md) / `BASELINE-SUMMARY.md`.

Чеклист: [docs/MEASURABLE-QUALITY.md](../../../../docs/MEASURABLE-QUALITY.md).
