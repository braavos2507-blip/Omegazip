Бесплатный архиватор для Linux

OmegaZip распространяется пакетом .deb (amd64) для Ubuntu/Debian — с GUI и CLI. Открывает .oz, ZIP и tar нативно; 7z/RAR — через установленный p7zip.

Установка

Скачайте .deb на странице загрузки (~5.8 МБ), затем:

sudo dpkg -i OmegaZip_0.4.0_amd64.deb

При ошибках зависимостей: sudo apt -f install

Форматы

Нативно: .oz, ZIP, tar. Для 7z/RAR/ISO: sudo apt install p7zip-full.

CLI

omegazip compress папка archive.oz
omegazip decompress archive.oz ./out

Бэкапы

omegazip repo backup ./repo ./data — дедуп между снимками.

Почему OmegaZip на Linux

Это не только GUI, но и удобный CLI для скриптов и CI, с собственным форматом .oz (дедуп + solid) и репозиторием бэкапов. Подробнее — в сравнении архиваторов.
