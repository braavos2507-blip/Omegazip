Частые вопросы

OmegaZip — бесплатный архиватор с форматом .oz, GUI и интеграцией в Windows/macOS.

Нужен ли 7-Zip?

Для .oz, ZIP и tar — нет. Для .7z, RAR, ISO, MSI и других форматов экосистемы 7-Zip — да, нужен установленный 7-Zip (Windows) или p7zip (Linux).

Чем .oz лучше ZIP?

На корпусах с повторяемостью (версии проектов, похожие файлы) .oz часто даёт меньший размер. На одиночных PDF/JPEG разница может быть минимальной. Подробнее — на странице формат .oz.

Как установить на Windows?

Скачайте setup.exe с страницы загрузки, запустите установщик. После установки — контекстное меню проводника и ассоциация .oz.

Если Windows показывает SmartScreen («неизвестный издатель»): нажмите «Подробнее» → «Выполнить в любом случае». Установщик пока без EV-подписи; скачивайте только с omegazip.ru.

Как установить на Linux?

Скачайте .deb (amd64), затем в терминале: sudo dpkg -i OmegaZip_0.4.0_amd64.deb. При ошибках зависимостей: sudo apt -f install.

Есть ли версия для macOS?

Да, DMG для Apple Silicon (M1/M2/M3). Откройте DMG и перетащите OmegaZip в «Программы». Intel Mac пока не поддерживается.

Если macOS блокирует запуск: Системные настройки → Конфиденциальность → «Всё равно открыть».

Это платно?

Нет. Можно поддержать разработку донатом — по желанию.

Безопасно ли скачивать с сайта?

Устанавливайте только с официального домена omegazip.ru или проверенных релизов проекта. Проверяйте подпись установщика, когда она доступна в релизе.
