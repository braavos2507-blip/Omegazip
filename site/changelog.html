Что нового в 0.4.0

Релиз от 15 апреля 2026. Скачать: страница загрузки.

Основное

  • Формат .oz v2: дедупликация, solid-потоки, шифрование, recovery
  • Пресеты сжатия: fast, balanced, max, ultra
  • Репозиторий бэкапов: init, backup, restore, prune, rclone-sync
  • Экспорт .oz → .zip, просмотр info/list, прогресс в GUI
  • Контекстное меню Windows и сервисы macOS
  • GUI + CLI для автоматизации

Платформы

  • Windows — setup.exe x64
  • macOS — DMG для Apple Silicon (aarch64)
  • Linux — deb amd64 (Ubuntu/Debian)

Известные ограничения

  • Расширенные форматы (.7z, RAR, ISO…) — нужен установленный 7-Zip / p7zip
  • macOS: публичный релиз без Apple notarization может показывать предупреждение Gatekeeper
  • Windows: установщик без EV-подписи — возможно предупреждение SmartScreen
  • Intel Mac пока не в релизе
