Бэкап папки как Borg

OmegaZip умеет не просто упаковывать, а вести репозиторий бэкапов: снимки, дедупликация между ними и восстановление любой версии. Бесплатно.

Как это работает

  • Дедуп — одинаковые блоки между снимками хранятся один раз, поэтому ежедневный бэкап почти не занимает места.
  • Снимки — каждый backup фиксирует состояние папки; restore возвращает нужную версию.
  • Recovery — в формате .oz есть блоки восстановления (Reed–Solomon) на случай частичной порчи.

Команды

ЗадачаКоманда
Создать репозиторийomegazip repo init ./myrepo
Снять снимокomegazip repo backup ./myrepo ./data
Список снимковomegazip repo list ./myrepo
Восстановитьomegazip repo restore ./myrepo 1 ./restored
Копия репо локальноomegazip repo push ./myrepo /mirror
В облако (S3/SFTP)omegazip repo rclone-sync ./myrepo remote:bucket

Облако подключается через rclone (S3, SFTP, …) — нативного SDK в .oz нет, синхронизируется папка репо.
