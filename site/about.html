О проекте

OmegaZip — практичный архиватор для повседневной работы: свой формат .oz, понятный интерфейс, интеграция в проводник и Finder, CLI для автоматизации.

Принципы

  • Бесплатно для пользователей, без подписок
  • Честные бенчмарки и публичные критерии качества релиза
  • Фокус на Windows и macOS, поддержка Linux
  • Развитие за счёт добровольных донатов

В планах

  • Установщик MSI с подписью для Windows
  • Сборка для Intel Mac
  • AppImage для Linux

Версия продукта: 0.4.0. Вопросы: Local-scan@yandex.ru.
