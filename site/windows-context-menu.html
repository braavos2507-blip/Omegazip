Сжатие из контекстного меню Windows

OmegaZip добавляет в проводник пункты «Сжать в .oz» и «Сжать в .zip». Папка упаковывается рядом — без запуска окна архиватора.

Как работает

  • Правый клик по папке/файлу → «Сжать в .oz» — архив появляется рядом.
  • Двойной клик по .oz открывает его и распаковывает рядом (тихо, без окна).
  • Ассоциация .oz с OmegaZip настраивается при установке.

Установка на Windows

  • Скачайте setup.exe на странице загрузки (~3.2 МБ).
  • Запустите установщик — меню и ассоциации добавляются автоматически.
  • При SmartScreen: «Подробнее» → «Выполнить в любом случае» (подпись EV пока не куплена).

Почему это удобно

Не нужно открывать программу, чтобы запаковать папку в отправленное письмо или бэкап. .oz при этом часто компактнее ZIP на похожих данных — см. сравнение.
